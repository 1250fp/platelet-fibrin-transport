# Attribution and provenance

- The mechanical model was informed by Michael et al. (2023),
  https://doi.org/10.1038/s42003-023-05240-z, and the accompanying Code Ocean
  capsule linked in `paper/refs.bib`. The planar adaptation is not the unmodified
  three-dimensional reference model. Licensing of derived material remains
  pending review; the repository's public visibility is not a license clearance.
- The reflection implementation is a force-free, constant-diffusion research
  implementation. It is not the general force-dependent propagator of
  Behringer and Eichhorn (2012). See the manuscript and supplement for attribution.
- NumPy, SciPy, Matplotlib, Pillow, Python, compiler and TeX distributions are
  external dependencies governed by their respective licenses.

Original source filenames and byte hashes are recorded in `data/file_manifest.json`.
`source_sha256` identifies the imported original; `sha256` identifies the distributed
file after any documented path normalization. External source paths use logical
labels described in `data/README.md`, not personal filesystem locations.
