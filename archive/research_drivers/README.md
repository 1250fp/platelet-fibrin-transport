# Historical research scripts

These preserve the research workflow, not a portable public batch interface.
Personal source roots have been replaced by logical `external_data/` labels;
layout assumptions and some expensive defaults remain. Do not run them directly
without restoring and reviewing the external archive and path mappings.
See the [data labels](../../data/README.md) and root README's `scripts/` commands.

The portable figure reproduction imports the historical `make_assets` function;
it does not execute the batch runner's `main`. Do not remove the archived plotting
module without first replacing that dependency.

Original import hashes and current distributed hashes are recorded separately
in `data/file_manifest.json`. Label changes are packaging changes, not new
mechanical or transport algorithms.
