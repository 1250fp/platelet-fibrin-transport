# Historical research scripts

These are source snapshots, not the portable public interface. They retain
original file layouts, absolute author paths and some expensive defaults.
Do not run them directly unless the expected data archive and path mappings
have been restored and reviewed. Use the root README's `scripts/` entry points.

The portable figure reproduction imports only the historical `make_assets`
function; it does not execute the historical batch runner or its `main` function.
