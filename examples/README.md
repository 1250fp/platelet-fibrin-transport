# Small reproducible examples

For the existing version, see the [mechanics configuration](../configs/legacy_program19_example.json), the [frozen transport protocol](../configs/paper/transport_protocol.json), and the [transport smoke test](../scripts/smoke_transport.py).

For the unified workflow, keep examples small enough to inspect: a seeded initial condition, a short mechanical run, or an escape check with a known expected outcome. Store full trajectories separately and reference them through manifests in [data](../data/README.md).
