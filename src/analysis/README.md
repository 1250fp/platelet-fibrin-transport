# Projection and analysis

This is the target for virtual sectioning, envelope contraction and spatial comparisons. Two comparisons have different interpretations:

- **Native 3D versus its projection:** section and project the same mechanical frame. The comparison is paired within clot.
- **Projected versus independent slabs:** compare independently generated cohorts at matched ages and slab counts. They do not share fibers, seeds or tracer starts.

The new analysis tools have not been imported here. The existing [paper figure script](../../scripts/reproduce_paper_figures.py) still reproduces the earlier archived outcomes.
