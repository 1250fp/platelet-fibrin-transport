# Initial conditions

Inputs for the solvers belong here: the cylindrical XML generator for volumetric runs, and the planar-network initializer for independent slabs. An XML describes an initial state, not a saved trajectory.

The new generators have not been imported on this branch. The earlier planar generator is documented in the [mechanics guide](../../docs/mechanics.md). When importing a generator, include a small seed/configuration example, its expected output and the upstream attribution.
