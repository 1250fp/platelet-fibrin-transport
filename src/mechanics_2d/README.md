# Independent planar mechanics

Target for the planar CUDA simulator. Each slab has its own planar network, seed and mechanical history. A stack is a collection of those slabs, not a set of sections cut from a volumetric simulation.

The current [planar mechanics core](../program19_core/) and [launcher](../program19_3.py) remain in their original locations. They are the earlier implementation, not the planned CUDA import.
