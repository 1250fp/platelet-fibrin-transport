# Volumetric mechanics

Target for the Michael-derived CUDA simulator. It evolves a connected 3D network from an input XML and writes snapshots of nodes, fibers, cohesive links and platelets. These native snapshots are the input for virtual sectioning and the volumetric transport reference.

The CUDA implementation is not included on this branch yet. Its eventual import should retain the upstream license and include a short XML-to-first-frame check.
