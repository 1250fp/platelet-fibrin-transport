# Tracer transport

Target for transport on frozen native 3D clots, their projections and independent slab stacks. An escape measurement must specify the tracer radius, release rule, solid and outer boundary conditions, observation horizon and treatment of censoring.

The [existing continuous-solid engines](../continuous_transport/) and their [smoke test](../../scripts/smoke_transport.py) remain available. They implement the earlier workflow; the newer three-representation escape analysis has not been imported into this directory.
